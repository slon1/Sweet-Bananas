## 1. Соглашения

| Параметр | Значение |
|----------|----------|
| Референс экрана | **1080 × 2160** px, портрет 9:16 |
| Система координат Figma | Начало в **левом верхнем** углу фрейма экрана |
| Дублирующая колонка | Слои с `X ≥ 1080` внутри экранного фрейма — копия арта/ UI для экспорта. Для вёрстки: **`x_ui = x >= 1080 ? x - 1080 : x`** |
| Unity UI (рекомендация) | Canvas Scaler **1080×2160**, `Match = Height`; позиции — через якорь + `sizeDelta` |

### 1.1. Рекомендуемый якорь из Figma (X, Y, W, H)

Для элемента с координатами от **левого верхнего** угла экрана (`x_ui`, `y`, ширина `w`, высота `h`), pivot **(0.5, 0.5)**:

| Зона экрана | Условие (нормализованный центр) | Unity `anchorMin` / `anchorMax` | `anchoredPosition` (относительно якоря) |
|-------------|----------------------------------|-----------------------------------|----------------------------------------|
| Верх-слева | `cx/w < 0.33`, `cy/h < 0.25` | `(0, 1)` | `(x_ui + w/2, -(y + h/2))` |
| Верх-центр | иначе верх | `(0.5, 1)` | `(x_ui + w/2 - 540, -(y + h/2))` |
| Верх-справа | `cx/w > 0.66`, верх | `(1, 1)` | `-(1080 - x_ui - w/2), -(y + h/2)` |
| Середина-слева | середина по Y | `(0, 0.5)` | `(x_ui + w/2, 1080 - y - h/2 - 1080)` — упрощённо: использовать **центр экрана** `(0.5, 0.5)` и `anchoredPosition (x_ui + w/2 - 540, 1080 - y - h/2)` |
| Низ / полноэкран | W≈1080, H≈2160 | `(0.5, 0.5)` stretch или `(0,0)-(1,1)` | по макету |

`cx = x_ui + w/2`, `cy = y + h/2` (от верха).

> **В магазине** координаты карточек на основном фрейме `shop` уже приведены через `x_ui` (см. §6).

## 7. Уровни и скины персонажа

### 7.1. Уровни (`game01`…`game26`)

В проекте **только** `Assets/Sprites/game/game01.png` … `game26.png` (26 штук).

Лишние инстансы на холсте Figma (`27`, `29` и т.д.) **не используем**.

| Спрайт | Назначение |
|--------|------------|
| `game/gameNN.png` | Фон/раскладка уровня N (1…26) |

### 7.2. Скины мармеладной ленты (`candy01`…`candy04`)

Скины **персонажа** (лента), не леденца в магазине:

| Спрайт | Слой Figma (реф.) |
|--------|-------------------|
| `game/candy01.png` | `01` |
| `game/candy02.png` | `33` |
| `game/candy03.png` | `32` |
| `game/candy04.png` | `31` |

Слои `30`, `02`, `03`, `04` на холсте — референс Figma, **игнорируем**; в билде только `candy01`…`04`.

### 7.3. Скины леденца на игровом экране (`pointer1`…`pointer4`)

**Рукоятка / леденец** на экране Game — **4 цвета**, те же, что в магазине. Активный цвет = **надетый** скин из shop (слоты 1…4).

| Спрайт | Цвет | Слот магазина | Карточки shop |
|--------|------|---------------|---------------|
| `game/pointer1.png` | Красный | 1 | `10_1` / `use1` / `bought_1` |
| `game/pointer2.png` | Оранжевый | 2 | `10_2` / `use2` / `bought_2` |
| `game/pointer3.png` | Голубой | 3 | `10_3` / `use3` / `bought_3` |
| `game/pointer4.png` | Зелёный | 4 | `10_4` / `use4` / `bought_4` |

Логика: при смене скина в магазине на Game показывается соответствующий `pointerN` (Sprite Swap / смена спрайта на `SpriteRenderer` рукоятки). Файлы — **спрайтлисты** (несколько кадров в одном PNG); для статичного вида брать нужный slice по настройке импорта.

**Отличие от `candy*`:** `candy01`…`04` — **мармеладная лента**; `pointer1`…`4` — **леденец-рукоятка** (цвет из магазина).

Размер инстанса уровня на макете: **741 × 647** px — зона цели; леденец визуально связан с левой частью экрана (GDD).

## 11. Замечания для вёрстки

1. **Готовый Loader** не меняем — спрайты `preload/*` уже привязаны в сцене.
2. Тексты **«Level 1»** и **«10»** (очки) в Figma — Text layers; в Unity — `TextMeshPro`, шрифт подбирается по GDD, не из PNG.
3. Слои `desktop 1`, `image 1/2` в `bg` — широкий параллакс-арт; в билде достаточно `game/bg.png` (или Scroll/scale по необходимости).
4. Для точных **Figma constraints** (left/right/center) нужен повторный проход с `get_design_context` после снятия лимита MCP или ручная сверка в Dev Mode.
