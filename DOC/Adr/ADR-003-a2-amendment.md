# ADR-003-a2: поправка к ADR-003 и a1 (по REPORT-002-A)

Статус: принято (архитектор). Приоритет над ADR-003 и ADR-003-a1 при противоречии.

## A8. Спавн ленты считается от видимой части палочки
Радиус головки 1.785 юн, палочка 4.726 юн. Спавн «25 % от оси» (1.18 юн) попадает внутрь круга головки, лента встаёт на купол и скатывается по нему, а не по палочке.
`along = HeadRadius + RibbonSpawnFraction × (StickLength − HeadRadius)`.
Доли рычага 0.05 и 0.90 (002-A, поправка 2) считаются по той же формуле.

## A9. Привод палочки
Правило «только `MoveRotation`» (ADR-003 D19) снимается для эксперимента. Разрешён привод через `angularVelocity`: в `FixedUpdate` `angularVelocity = clamp(DeltaAngle(target, rotation) / dt, ±speed)`. Способ выбирается по A/B-замеру (E1). Вариант должен давать измеренную `angularVelocity` ≥ 570°/с при команде 600°/с (A1).

## A10. Критерий D24 п. 1 (рабочий, на раунд A2)
Зазор = расстояние между якорями соседних сегментов (по позе `Rigidbody2D`).
- 0 бросков с зазором > 0.21 юн;
- не более 5 % бросков с зазором 0.085…0.21 юн;
- NaN = 0, скорость сегмента ≤ 60 юн/с.
Порог 0.085 (8 px) жёсткий для визуала; решение о его смягчении принимаю по гистограмме E0.

## A11. Бенч-раннер
Остаётся в `Assets/Editor/SpikeBench/` (editor-код, asmdef не нужен) до конца 2B. Удаляется последним коммитом 2B. Использует код рантайма и `FixedUpdate`, логику ввода и ленты не копирует.

## A12. Форма ленты (новый критерий D24 п. 11)
Наблюдение оператора: лента сворачивается в комок, по форме близкий к кругу. Причина по коду: шарниров `SegmentCount − 1 = 7`, предел `JointLimitDeg = 65°`, суммарный изгиб до 455° > 360°. Цепь способна замкнуться в кольцо. Возвращающий момент `k = 2` слишком слаб против веса цепи. Визуальная толщина 1.17 юн при физической 0.3 юн: при изгибе полосы перекрываются и читаются как шар.
Правило: лента остаётся лентой.
- Конструктивно: `(SegmentCount − 1) × JointLimitDeg ≤ 200°`, кольцо невозможно.
- Метрика `R = |якорь начала − якорь конца| / полная длина`.
- На палочке в покое после спавна `R ≥ 0.9`.
- В полёте и после остановки `R ≥ 0.35` в каждом кадре каждого броска.
- Визуально: кадры в рапорте (на палочке, в полёте на пике, после остановки).

## A13. Коллайдер головки
Пока оператор не ответил по продуктовому вопросу, по умолчанию коллайдер головки включён (лента может лечь на голову и сползти). Отключение головки в E2 — только эксперимент.
