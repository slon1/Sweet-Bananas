# ADR-003-a9: стоп B3 по A34, развилка геометрии покоя (поправка к ADR-003, a8)

Статус: **ожидает решения** (архитектор / оператор). Приоритет над ADR-003, a1–a8 при противоречии после принятия. Основание: REPORT-002-B3, коммит `253d957`, ADR-003-a7 (A29), ADR-003-a8 (A33–A34).

## A35. Итог TASK-002-B3

1. **A29 подтверждена** (цель выключена, `LevelRules` выкл., коллайдер цели откл.): tip на доле 0.25 при `StickFriction` **0.10** достигается (~1.39 с). Правка `Lollipop.ApplyStickMaterial` (B2) сохраняется; гипотеза a7 о дефолтном трении головки снята для фазы «без цели».
2. **Зазоры кончика → цель** при текущих положениях леденца и цели в допуске сетки a8 (−25°…−45°, 0.044…0.34 юн). Геометрия «в лоб» не объясняет стоп.
3. **A34 не выполнена ни для одного угла** сетки: пассивный тест (цель вкл., `LevelRules` вкл., spawn 0.25, 10 с, 12×, `StickFriction` 0.10) — исход `Timeout`, **непрерывный контакт ленты с целью ~8.5–9.4 с** (требование ≤ 0.5 с), кончик не достигается. Соответствует A33: лента в покое опирается через палочку/головку в цель.
4. По TASK-002-B3 п. 2.4 — **стоп**; п. 3–5 (финальный `StickFriction`, TapSpeed, D24.1) **не выполнялись**. `GameConfig.asset` **без изменений** (`RestAngleDeg` по-прежнему −25° в ассете, выбор не валидирован).

**Временное значение для диагностики (не в GameConfig):** `StickFriction` **0.10** для пассивной фазы B3.

## A36. Продуктовая развилка (нужен выбор)

Задача B3 **не** расширяет сетку углов и **не** двигает леденец/цель без отдельного решения (a8, п. 2.4; TASK-002-B3 п. 4). Допустимые направления — **ровно одно** утверждается здесь или в поправке к a9:

| ID | Направление | Следствие | Затрагивает заморозку a8 |
|----|-------------|-----------|---------------------------|
| R1 | **Сдвиг цели** (вниз/в сторону от кончика) или **сдвиг точки покоя леденца** | Новая сетка зазоров и повтор пассивного теста; возможен новый TASK (только сцена/трансформы, без физики ленты) | Да — положение цели/головки |
| R2 | **Удлинить зазор** иным способом (короче палочка, иной `RestAngle` вне −25…−45, иная длина ленты) | Только если архитектор явно снимает заморозку длины/угла; иначе вне scope | Да |
| R3 | **Уточнить A34** (например, контакт только «лента→цель» без учёта касания цели через палочку/головку; или иной порог / иная доля spawn) | Новая формулировка критерия + повтор B3 п. 2 | Нет по геометрии |
| R4 | **Принять покой с контактом** и править **условие победы** (`LevelRules`) / метрику пассивной победы | Риск регрессии GDD §3; отдельный ADR по правилам | Частично |
| R5 | **Остановить подбор 002-B** до дизайн-ревью уровня 1** (макет, GDD §2 «≈ −25°») | Playability и Android D24.10 не блокируются документально, но кодовый конфиг не финализируется | — |

**Не делать без решения:** подбор `TapSpeed`, финальный `StickFriction`, запись `RestAngleDeg` в `GameConfig`, расширение сетки углов «на глаз».

## A37. Рекомендуемый следующий шаг (после выбора в A36)

3. До принятия a9: `RestAngleDeg`, `TapSpeedDegPerSec`, финальный `StickFriction` в репозитории **не менять**; этап 2B (играбельность) считается **на паузе** (см. `DOC/PLAN.md`).
