# TASK-002-A: поправка 1 (ответ на вопрос о положении леденца)

Всё, что здесь не упомянуто, остаётся как в TASK-002-A и ADR-003-a1.

## 1. Какой слой в Figma — леденец
Слой `01` (905×905) из `screens.md` **не** леденец, игнорировать. Леденец в кадре `Game1` (`1225:85`) — слой-картинка **729.37 × 729.37** с поворотом **106.38°** (это `pointerN`, масштаб ≈ 99.9 %); он стоит у левого края, головка частично за краем кадра, палочка идёт вправо. Найти его через `get_metadata` по размеру 729.37×729.37 внутри `1225:85`. Если кандидатов больше одного — **остановиться и спросить**. В рапорт: node id, имя слоя, `relativeTransform`/координаты.

## 2. Центр головки (оператор вручную проставляет pivot)
Оператор в Sprite Editor ставит у `game/pointer1.png … pointer4.png` (режим Single, PPU 100) **Custom pivot в центр спирали головки**. Cursor `.meta` этих файлов не правит; изменения `pointer*.png.meta` от оператора — в коммит 002-A (перечислить в рапорте).

Следствие для реализации (правка ТЗ п. 2, `Lollipop`):
- Origin объекта со `SpriteRenderer` совпадает с центром головки, поэтому дочерний объект спрайта стоит в `localPosition = (0, 0, 0)`; поправка ориентации (если палочка в PNG смотрит не вправо) — только поворот этого дочернего объекта вокруг origin. Ручного смещения не нужно.
- Проверить в коде/рантайме `sprite.pivot` (px) против центра головки на 4 спрайтах: в рапорт значения pivot для каждого и вывод «совпадает с головкой» (по просмотру PNG).
- Ось `Rigidbody2D` = центр головки = положение леденца.

## 3. Мировая позиция головки
Из Figma берётся **только положение центра головки** (поза леденца в Figma — не источник истины, D19). Расчёт: взять трансформ слоя (`relativeTransform`) в кадре `Game1`, применить его к пикселю pivot из п. 2 (учесть масштаб 729.37/730), получить точку в пикселях кадра; затем `world = (x/100, (2160 − y)/100)` (ADR-002 D11). Центр головки может оказаться за левым краем мира (x < 0): это допустимо, коллайдер головки частично вне экрана. Проверка по `preview/Game1-1.png`. Расчёт и итоговые значения (px и юниты) — в рапорт.
