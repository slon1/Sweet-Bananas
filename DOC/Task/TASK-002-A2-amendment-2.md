## Блокирующие (до E0)
**B1. Выборка по каждому шагу физики, а не по кадру редактора.**
Сейчас `SampleFixedStep()` вызывается из `EditorApplication.update` циклом `while (FixedSteps > _lastFixedSteps)`. При `timeScale` 12 за один кадр редактора проходит около 12 шагов физики, цикл читает одно и то же состояние 12 раз: пики зазора между кадрами теряются, таймеры «остановки» и «0.1 с после спавна» идут по устаревшему состоянию.
- В `ThrowController` добавить `public event System.Action DebugFixedStep;` (только под `UNITY_EDITOR || DEVELOPMENT_BUILD`), вызывается в конце `FixedUpdate`. Бенч подписывается на него и делает всю выборку в этом вызове. Другой логики в рантайм не добавлять.
- `_phase` вычислять **до** обновления максимума зазора (сейчас зазор получает фазу предыдущего шага).
- Исключение первых 0.1 с после спавна считать по числу шагов `FixedSteps`, а не по `Time.time`.

**B2. Зазор и R по позе `Rigidbody2D`.**
`MaxAnchorGap` и `ComputeR` читают `transform.TransformPoint`, то есть интерполированную позу. A10 требует позу тела. Заменить на `Rigidbody2D.GetPoint(localAnchor)` (или `position` + `rotation`), якоря по-прежнему `±SegmentLength/2` по локальному X.

**B3. Сетки бросков.**
- Тапы: длительность нажатия должна быть ≤ `HoldThresholdSeconds` (0.15 с). Сейчас в сетке 0.16 / 0.2 / 0.28 / 0.4, это 40 % «тапов» на самом деле удержания. Новая сетка: 0.04 / 0.06 / 0.08 / 0.10 / 0.12 / 0.14.
- Удержания: 0.3 / 0.5 / 0.8 / 1.0 / 1.2 / 1.5 с (как в поправке 2 к 002-A, а не 0.4…6 с). У каждого второго удержания после возврата в `Rest` (`ThrowController.State == Rest` в первый раз) сразу повторный тап 0.08 с; эта часть броска входит в замер.
- Выбор бросков детерминированный и равномерный: полная сетка (доли спавна × длительности) перемешивается по seed и проходится по кругу до нужного числа бросков, а не `rng.Next` с повторами (иначе часть ячеек не будет покрыта). Сетку и порядок записать в методику.

**B4. Критерий остановки по поправке 1.**
`AllStopped` сейчас дополнительно требует `|angularVelocity| < 2.5°/с`. В поправке 1 только `|v| < 0.05` линейная. Убрать угловое условие (или явно записать в методику и обосновать замером; по умолчанию убрать).

**B5. Проверка на 1×.**
- 10 бросков для проверки брать не первые 10 (все тапы), а 8 тапов и 2 удержания с равным шагом по индексам.
- Бенч сам сравнивает 12× и 1× по тем же планам и печатает: число совпадений флага A10, разницу максимального зазора по броскам, отдельную строку «совпало / не совпало» в `summary`. `experiment_id` в summary проверки на 1× должен нести суффикс `_verify1x`.
