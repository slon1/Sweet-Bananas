## 1. Эксперименты
Порядок обязателен. Каждый шаг начинается от лучшего состояния предыдущих; то, что не помогло, откатывается. Одна переменная за шаг.

- **E0.** Базовая линия: повторить 002-A, добавить гистограмму и разбивку по фазам.
- **E1.** Привод палочки: `MoveRotation` против `angularVelocity` (A9). Проверить A1 (≥ 570°/с при 600°/с). Записать поведение ловли и рычага.
- **E2.** Геометрия: (а) спавн по A8; (б) то же и отключённый коллайдер головки (только эксперимент, A13). Замерить время скольжения и скорость при 0° через 1 с и через 2 с.
- **E2s.** Форма (A12): `JointLimitDeg` 65 / 35 / 25 / 15; затем `RestoreK` ×1 / ×5 / ×20 при лучшем пределе; затем `RibbonColliderThickness` 0.3 / 0.4 (не больше длины сегмента). Записать R и зазоры.
- **E3.** `Continuous` против `Discrete` на сегментах.
- **E4.** Возвращающий момент: K = C = 0, затем K/2, C/2 от лучшего состояния E2s.
- **E5.** Обзор API `Physics2D` / `Rigidbody2D` / `HingeJoint2D` в 6000.5: перечислить свойства солвера (подшаги, жёсткость и частота контактов и шарниров, демпфирование). Проверить, меняют ли результат `velocityIterations` / `positionIterations` (4 против 24). Применить найденные ручки (значения в `GameConfig`).
- **E6.** `SegmentCount` 6 / 8 / 10; `SegmentMass` 0.2 / 0.5 / 1.
- **E7.** Свип `TapSpeed` 100…600°/с, график зазор против скорости.
