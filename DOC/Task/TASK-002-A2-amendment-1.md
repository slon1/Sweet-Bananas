## 3. Метрики (операциональные определения)
- **Зазор:** по позе `Rigidbody2D` (A10). В таблице отдельные столбцы: сырой максимальный зазор и «считается разрывом по A10» (да/нет).
- **Фазы броска.** Контакт: хотя бы один сегмент `IsTouching` коллайдера палочки или головки. Полёт: нет контакта с леденцом и ещё не остановка. Остановка: все сегменты `|v| < 0.05` непрерывно 0.25 с. Зазор фиксируется вместе с фазой, в которой он достиг максимума.
- **R (A12).**
  - `R_rest`: R через 1.0 с после `ResetToSpawn` в покое, без нажатия, до того как лента доедет до кончика. Критерий ≥ 0.9.
  - `R_min_throw`: минимум R за бросок, **исключая первые 0.1 с после `ResetToSpawn`**. Критерий ≥ 0.35.
- **Скольжение (D24.9):** время от спавна до кончика; скорость сползания при 0° через 1 с и через 2 с.
- **E1, играбельность:** помимо A1 записать максимальный перелёт угла за цель (при удержании: максимум |угол − 0°|; при тапе: максимум угла − 35°) и время выхода на 0°.

## 4. Выбор «лучшего состояния» и откат
Лексикографический порядок:
1. A10 выполнен на серии 100+20;
2. A12 выполнен;
3. меньше разрывов по A10;
4. меньше сырой максимальный зазор;

Если после шага результат не лучше по этой шкале, шаг откатывается.

## 5. Изменения в списке экспериментов
- **E2s (форма).** При 65° критерий A12 заведомо диагностический: записать это в рапорт. Фильтр `(SegmentCount − 1) × JointLimitDeg ≤ 200°` намеренный; при 8 сегментах проходят пределы ≤ 28°. Сетка 65 / 35 / 25 / 15: рабочие кандидаты 25 и 15.
- **Новый E2f (после E2s).** Подбор `StickFriction` под D24.9. Смешанное трение Box2D `√(ленты × палочки)` должно быть ниже tan 25° = 0.466, то есть при `RibbonFriction` 0.9 нужно `StickFriction` < 0.24. Сетка: 0.05 / 0.10 / 0.15 / 0.20 / 0.24. Порядок обязательный: A8 → E2s → E2f. Значение 0.4 из 002-A работало только потому, что лента ехала по куполу головки.
- **Промежуточный стоп после E2s.** Если A12 не выполняется ни при одном пределе из сетки (в том числе с K ×20 и толщиной 0.4), E3–E7 не начинать, вопрос в чат (по аналогии с D24.8).
- **E5.** Добавить одну строку: `sleepMode` StartAwake против NeverSleep.
- **E6.** При смене `SegmentCount`: пересчитывать длину сегмента (3.39 / count), проверять `RibbonColliderThickness ≤ длина сегмента`, предел шарнира масштабировать как ≤ 200° / (count − 1).
- **E7.** Финальный `TapSpeed` — любое значение, проходящее A10, A12 и рычаг ≥ 2 юн. Из нескольких брать ближайшее к 600°/с; значение ниже 300°/с допустимо только с пометкой в рапорте.
- **Приоритеты при конфликте критериев:** 1 и 11 жёсткие; затем 9; затем 4. Критерий 4 нельзя нарушать (vy < 0.5, подъём ≤ 0.2), но «лучше прежнего» не требуется. Если после E2f пп. 9 и 4 несовместимы, в рапорт таблицу компромисса и стоп, решение за мной.
- **E0, гистограмма.** Если в E0 в бине 0.085–0.21 окажется > 5 %, Cursor присылает гистограмму в чат сразу после E0 и продолжает с E1, не дожидаясь ответа. Решение о пороге 0.085 принимаю я по гистограмме. До моего ответа критерий A10 действует как есть.
