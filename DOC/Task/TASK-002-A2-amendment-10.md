**2.4. D24.3 Рычаг** (определение A6): одинаковый тап (длительность 0.08 с), спавн у основания (доля 0.05) и у кончика (доля 0.90 по A8). Если лента при 0.90 не падает через `pivot.y` (улетает или падает мимо) — записать как есть. Повторить по 5 раз для каждой доли и дать среднее и разброс.

**2.5. D24.4 Ловля** (определение A6): лента падает с высоты 3 юн над удерживаемой палочкой (0°). Отсчёт 0.3 с от первого контакта. Порог: вертикальная скорость центра < 0.5 юн/с, максимальный подъём центра после первого контакта ≤ 0.2 юн. Постановка ленты: `Ribbon.DebugPlace` над палочкой, ленту падаем без спавна по A8. 5 повторов с разным сдвигом по X (по 0.5 юн от центра палочки).

**2.6. D24.7 Производительность:** средний шаг физики (Profiler, editor, `Physics2D.Simulate`) и GC Alloc меша по кадрам. Порог ≤ 1 мс и 0.

**2.7. A1:** не применяется (привод `MoveRotation`). В рапорте одной строкой: измеренная скорость палочки по `DeltaAngle/dt` при тапе (максимум).

## 3. Критерии закрытия (A21, ADR-003-a5)
Серия 2.1, валидные броски:
1. NaN = 0; скорость сегмента ≤ 60 юн/с.
2. **Фаза `stopped`:** зазор между якорями ≤ 0.05 юн на каждом шаге этой фазы (лента остановилась целой).
3. Бросков с первым зазором > 0.21 юн (в любой фазе) ≤ 2 % валидных (≤ 7 из 360).
4. A12: `R_min ≥ 0.35` в каждом броске (без первых 0.1 с).
5. `spawn_invalid` ≤ 2 %.

Прочее: D24.2 (0 нарушений), D24.3 (≥ 2 юн), D24.4 (оба условия), D24.7, D24.9 (2.5–4 с; при 0° через 1 с < 0.05 юн/с).

**Если критерий не выполнен — не подбирать параметры.** Остановиться, дать числа и разбивку (по долям спавна, по `kind`, по фазам) и ждать решения. Исключение: D24.9. Если время скольжения вне 2.5–4 с, записать значение и таблицу по долям, ничего не менять. Приоритет критериев: 1–2 и 4 жёсткие, затем D24.9, затем D24.4.
