# TASK-000: поправка 2 (ревью плана Cursor от поправки 1)

План принят с четырьмя уточнениями. Остальное — как в плане Cursor.

## 1. Проверка HingeJoint2D не в Scene.unity
Сцену `Scene` потом сохраняем (п. 5), и временный `HingeJoint2D` мог бы попасть в файл. Проверять так: в новой безымянной сцене (`NewScene`, не сохранять) или проверкой типа (`typeof(HingeJoint2D)` и `AddComponent` на временном объекте с немедленным удалением). Только после этого открывать `Scene` и менять Match.

## 2. Что редактор меняет сам при открытии
Первый запуск в 6000.5.9f1 может переписать ассеты и настройки без нашего участия. Сразу после разрешения пакетов и до остальных правок:
- выполнить `git status` и `git diff --stat`, вложить в рапорт;
- допустимо коммитить: `manifest.json`, `packages-lock.json`, `UNITASK_DOTWEEN_SUPPORT` в `ProjectSettings.asset`, папки и их `.meta`, `Scene.unity`, `screens.md`, рапорт, `.meta` кнопки (если создан редактором);
- **любые другие изменённые файлы** (другие `ProjectSettings/*`, `.meta`, сцены, префабы) в коммит не включать молча: перечислить в рапорте с причиной, откатить через `git checkout -- <файл>` только то, что не относится к задаче, остальное оставить на решение архитектора.
- Для `ProjectSettings.asset` отдельно показать diff: ожидается только строка define (если редактор обновил версионные поля, перечислить).
- Если после открытия появились не ожидаемые изменения в `ProjectSettings` (переход версий), записать их и не откатывать то, без чего проект не откроется; вопрос архитектору.

## 3. Временные editor-скрипты
Скриптов в задаче быть не должно. Если для правки через SerializedObject, define или проверки типа нужен одноразовый editor-скрипт или `-executeMethod`: создать вне `Assets/Scripts`, выполнить, **удалить вместе с `.meta` до коммита**, указать в рапорте, что был использован и удалён. В `git status` перед коммитом таких файлов быть не должно.

## 4. Закрытие чужих экземпляров Unity
Cursor не убивает процессы. Если проект открыт в редакторе оператора, Cursor останавливается и просит оператора закрыть его (через чат), затем продолжает.

## 5. Пути
Папка задач в репозитории называется `DOC/Task/` (как у оператора). Дальше все ТЗ и поправки лежат там, ADR — в `DOC/adr/`, рапорты — в `DOC/reports/`.

## Проверка перед пушем
1. `git status` показывает только файлы из списка допустимых.
2. `git lfs ls-files` включает `Assets/Sprites/pop-up/play again.png`.
3. Консоль чистая, `Scene.unity` diff — одна строка, `Loader.unity` без изменений.
