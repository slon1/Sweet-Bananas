## 1. Доработки каркаса (по ревью рапорта 001)
1. **Фон по ADR-002 D12 (новая редакция):** в `BackgroundCanvas` убрать `AspectRatioFitter`; `Image` размером 1080×2160, якорь и pivot снизу по центру. Цвет камеры (`Main Camera → Background`) — средний цвет верхней строки `game/bg.png`. Проверить на 1080×1920, 1080×2160, 1080×2340: низ фона совпадает с низом экрана, шва вверху нет.
2. **`PlayerPrefsSaveService`:** оборачивать разбор JSON в `try/catch`; при ошибке — значения по умолчанию и `Debug.LogWarning`.
3. **Импорт спрайтов (правка `.meta` разрешена только для этих файлов):** `game01…26.png` перевести в режим **Single** (PPU 100, центр pivot, Generate Physics Shape включён). Причина: в режиме Multiple слайсы обрезаны и сдвинуты, а в макете цели лежат в общей рамке 741×648. Для `candy01…04.png` и `pointer1…4.png` записать в рапорт размер текстуры и режим импорта; `candy` при Multiple перевести в Single, `pointer` уже Single, не менять.

## 3. Уточнения (ответы на вопросы Composer)
1. **Цвет камеры:** взять верхнюю строку пикселей `bg.png` (первая строка файла, не `y = 0` в координатах Unity), усреднить RGB с весом по альфе, полностью прозрачные пиксели не учитывать. Записать в рапорт hex/RGB и способ замера (скрипт по файлу PNG без включения Read/Write на текстуре). Критерий «шва нет» — стык фона и верхней заливки на 1080×2340 не заметен; небольшая разница оттенка не блокирует, но фиксируется в рапорте.
